# Flat Cherry Linux

A lightweight Void Linux-based desktop distribution focused on Flatpak applications.

## Current target

- **Base:** Void Linux (glibc)
- **Init:** runit
- **Desktop:** LXDE on X11
- **System packages:** XBPS
- **Applications:** Flatpak, with Flathub preconfigured
- **Firmware:** AMD and NVIDIA firmware included
- **Architecture:** x86_64 (initial milestone)

ISO images are built with GitHub Actions. The project maintainer does not need a local Linux build machine.

See [docs/BUILDING.md](docs/BUILDING.md) for the build process and validation status.
